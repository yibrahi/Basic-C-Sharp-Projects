# Basic C# Projects

This repository contains C# and .NET projects completed while learning software development using Visual Studio. These projects demonstrate my understanding of C# fundamentals, object-oriented programming, ASP.NET MVC, Entity Framework, databases, and application development.

## Projects

### Package Express
A console application that calculates a shipping quote based on package weight and dimensions.

### Method Assignment
A console application demonstrating how to create and call methods with parameters.

### Polymorphism Assignment
A console application demonstrating interfaces and polymorphism using an `IQuittable` interface and an `Employee` class.

### Operator Overload Assignment
A console application that overloads the `==` and `!=` operators to compare Employee objects using their ID values.


### Car Insurance
An ASP.NET MVC web application that collects customer and vehicle information and automatically calculates an insurance quote.

The application uses Entity Framework to store customer information in a database and includes Create, Edit, Details, Delete, Index, and Admin functionality.


### Student Code First
An Entity Framework Code-First console application that creates a Student database from C# classes and adds a student to the database.
